# Agent Guard для VS Code

Локальная панель подтверждения MCP-действий. Это интерфейс собственного сервера
Agent Guard, не замена расширений Codex/GigaCode и не автоматический перехват их инструментов.

Установить локальный VSIX через Extensions → Install from VSIX, затем открыть
доверенную рабочую папку. Запустить сервер Agent Guard либо ручную проверку.
Панель появится рядом с редактором при запросе решения. Вручную:
Command Palette → Agent Guard: открыть панель. В строке состояния есть кнопка Guard.
Если серверов несколько — Agent Guard: выбрать сервер.

Расширение само ничего не разрешает. Кнопки «Отказать» и «Разрешить один раз»
передают решение выбранному серверу. При отсутствии объяснения подпись разрешения
явно указывает это. Закрытие панели отменяет текущую попытку. Результат сохраняется
на экране; при завершении сервера отображается потеря связи отдельно от результата.

Нужен запущенный MCP-сервер с записью в стандартном служебном каталоге пользователя.
Секрет сессии читает только extension host; в Webview он не передаётся.
Полное меню политик/LLM и системное хранилище ключей ещё не реализованы.
Поддержка локального desktop VS Code на macOS/Windows требует реального прогона;
SSH, WSL, Dev Containers, vscode.dev и другие удалённые среды пока не поддержаны.

Автоматическое открытие панели можно отключить настройкой agentGuard.autoOpen.
Расширение не публикуется в Marketplace; пакет предназначен для локальной проверки команды.
