# Agent Guard для VS Code

Панель подтверждения локального MCP-сервера Agent Guard. Это отдельный интерфейс,
а не изменение чатов Codex/GigaCode и не автоматический перехват их инструментов.

Установить VSIX через Extensions → Install from VSIX…, затем Reload Window.
Открыть доверенный локальный проект и запустить сервер Guard через OpenCode
или ручную проверку. Старые MCP-процессы после обновления нужно перезапустить.

Панель появляется рядом с редактором при запросе решения. Вручную:
Agent Guard: открыть панель; при нескольких серверах — Agent Guard: выбрать сервер.
Автооткрытие отключается agentGuard.autoOpen. Явный выбор сервера имеет приоритет.

Кнопка «Настройки» либо Agent Guard: настройки открывает нативное меню:

- Политики: переключение block/ask для четырёх реализованных категорий, затем «Сохранить».
- Подключение LLM: адрес, модель, timeout, новый ключ/окружение/без ключа.
- Проверка подключения без выполнения команды.
- Удаление выбранного сохранённого ключа и диагностика хранилища тестовым значением.

Ключ вводится в скрытом Input Box и сохраняется через SecretStorage VS Code.
В Webview и обычный JSON он не возвращается. Настройки сохраняются вне проекта,
отдельно для его канонического пути. Host повторно загружает ключ в память нового
сервера. При смене адреса требуется новый выбор источника ключа.
Изменения отменяют ожидающие попытки; во время исполнения настройки не меняются.
При ошибке хранилища ключ не сохраняется открытым текстом.

«История сессии» хранит в памяти сервера 50 последних завершённых попыток,
с решением и результатом. Длинные данные сокращаются с пометкой. История исчезает
после остановки сервера и не даёт разрешать или повторять старые действия.

Закрытие панели отменяет ожидающую попытку. Разрешение действует один раз.
Отсутствие объяснения требует отдельного явного разрешения без объяснения.
При остановке сервера последний полученный результат остаётся виден отдельно
от сообщения о потере связи.

Пользователь подтвердил основной сценарий 0.0.3 на Mac; меню/SecretStorage 0.0.4
и Windows ещё требуют реального прогона. Автотесты с mock host его не заменяют.
Поддержка как цель: локальный desktop VS Code macOS/Windows. SSH/WSL,
Dev Containers и vscode.dev не включены. В Marketplace расширение не опубликовано.
