## Что реализовано

- `src/core/index.ts` — публичный вход: createCore, validateConfig, типы обмена.
- `core.ts` — проверка входа/конфигурации, применение политик, замороженные снимки.
- `shell.ts` — ограниченный разбор литеральных аргументов и простых частей команды.
- `rules.ts` — rm, разрушительные Git-операции, force push, внешняя папка/цели rm.
- `paths.ts` — канонизация, проверка границ каталогов и символических ссылок.
- `types.ts` — контракты действия, результата, правил, объяснения и решения человека.
- `tests/core.test.ts` — тесты на синтетических временных данных.
- `package.json`, `package-lock.json`, `tsconfig.json`, `.gitignore` — сборка и проверки.

Runtime-зависимостей нет. Инструменты разработки: TypeScript 7.0.2,
@types/node 24.19.4; точные версии и зависимости сохранены в lock-файле.
Фактическая проверенная среда: macOS, Node.js v24.21.0.

## Повторение

Из корня репозитория, при установленном Node.js 24:

```sh
npm ci --ignore-scripts
npm run check
npm test
```

`npm run check` проверяет типы. `npm test` компилирует TypeScript и запускает
node:test. Сборка записывается в игнорируемый `dist/`; библиотечный вход —
`dist/src/core/index.js`. Это библиотека ядра, не готовый MCP-сервер или CLI.

Для текущей самопроверки зависимости установлены через npm install
с отключёнными install scripts и отдельным кешем в /private/tmp;
сохранён lock-файл. Команда npm ci дана для повторения другим участником.

| 1. Контракт | Один формат входа, результата и обмена | Экспортированные типы, фикстуры available/unavailable/UserDecision компилируются; есть тест обмена. Сквозное подключение ещё не проверено. |

| 3. Неопределённость | Не выдавать частичный анализ за полный | Обёртки, подстановки, wildcard, незакрытые кавычки, Git global options и составные команды дают partial/unknown. Найденный запрет сохраняется. |

| 5. Снимок | Нет подмены через исходный объект или вложенные поля | Изменение входа, вложенных рисков/путей, конфигурации и результата не меняет действие; повтор/изменённый запрос дают новый UUID. |

## Ограничения и непроверенное

- Меню политик, хранение JSON, применение новых настроек к ожидающим решениям — 004/006.
  Ядро создаёт неизменяемый экземпляр для переданной конфигурации.
- Нет подключения OpenCode, реальной LLM, доверенного UI или исполнения процесса.
  Возвращённое ask не является разрешением; actionId не является полномочием.
- Нет универсального shell-разбора, Fast, постоянных разрешений, защиты чтения
  секретов, OS-песочницы и корпоративных обязательных политик.
- Неизвестная форма с ask может скрывать запрещённую операцию. Автоблокировка
  работает только для распознанных форм; отсутствие совпадения не доказывает безопасность.
- affectedPaths не перечисляет содержимое удаляемых каталогов и последствия Git.
  В составных командах относительные цели не вычисляются. Ссылки наружу
  трактуются консервативно; возможны лишние запреты при удалении самой ссылки.
- Снимок не фиксирует содержимое файлов и не исключает гонки. Проверка состояния
  перед исполнением относится к 006. Другие ОС и версии Node не проверены.
- Полнота каталога бизнес-метрик и источников по 002 — отдельная незавершённая работа;
  эта реализация не объявляет требования заказчика или все цели PRD выполненными.
