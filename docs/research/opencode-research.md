### Влияние на Agent Guard

- OpenCode v2.4.x - активный проект от Anomaly Co, регулярно обновляется.
- Поддержка MCP встроена (упоминается в документации).
- Два встроенных агента: build (полный доступ) и plan (только чтение).
- Доступен как CLI, так и Desktop App (macOS/Windows/Linux).
- Подходит для Демо 2 - проект стабилен.

### Найденное в схеме OpenCode v2.x

#### MCP Configuration (packages/schema/src/mcp.ts)
- type: "local" | "remote", command: string[], cwd, environment, disabled, codemode, pool, protocol
- timeout: { startup, catalog, execution }

#### Permissions (packages/schema/src/permission.ts)
```typescript
interface Rule {
  action: string;      // tool name (shell, file_edit)
  resource: string;    // "*" или path pattern
  effect: "allow" | "deny" | "ask";
}
```

#### Policies (packages/schema/src/config/policy.ts)
Действия: provider.use, tool.use, integration.connect, mcp.use, skill.use, plugin.use, websearch.use
