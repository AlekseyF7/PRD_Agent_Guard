# PRD_Agent_Guard

Agent Guard — плагин безопасности для кодинговых агентов. Его цель — перехватывать опасные действия до выполнения, объяснять последствия простыми словами и запрашивать явное подтверждение пользователя, сохраняя полезную автоматизацию. Целевая аудитория — новички, студенты и начинающие разработчики.

## Архитектурная идея

Общее ядро отвечает за правила риска, объяснение последствий, оценку зоны воздействия, решения о подтверждении, калибровку строгости и аудит. Адаптер для каждого агента связывает ядро с доступными механизмами перехвата и взаимодействия с пользователем. Глубина поддержки зависит от API конкретного агента и подтверждается техническим экспериментом.

## План команды

Демо 1 → Демо 2 → Демо 3 (финал, сессия). Это план команды, а не утверждённые заказчиком критерии приёмки.

| Этап | Планируемый результат |
| --- | --- |
| Демо 1 | Продуктовое исследование: аудитория, проблема, аналоги, УТП и обоснование применения ИИ. Живой показ кликабельного UX-прототипа, архитектура и распределение ролей. Технический эксперимент с OpenCode при наличии времени. |
| Демо 2 | Ограниченный работающий сценарий в OpenCode: перехват выбранной опасной shell-команды, оценка риска, объяснение, подтверждение или отказ и запись решения в журнал. GigaCode Desktop — желательное направление для технической проверки по предложению заказчика. |
| Демо 3 — финал, сессия | Расширение сценариев, тестирование и измерение метрик PRD. Разработка адаптера GigaCode Desktop зависит от результатов технической проверки. |

Целевые метрики PRD: обнаружение и блокировка до выполнения 100% опасных команд из тестового набора с 50+ паттернами; ложные срабатывания менее 10%; калибровка менее чем за 3 минуты с выбором одного из трёх уровней; оценка чувства контроля 4+/5 от 5+ пилотных пользователей. Это цели для проверки, а не достигнутые результаты.

Claude Code пока не включён в обязательный план реализации. Другие агенты из PRD — Claude Code, Cursor, Cline, Codex CLI, Aider и Windsurf — последующие кандидаты. Возможная глубина поддержки различается: перехват до выполнения, настройка разрешений, восстановление или рекомендации по конфигурации; она требует отдельной проверки.
