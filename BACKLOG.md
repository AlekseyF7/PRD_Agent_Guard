# Бэклог Agent Guard

Исполнитель отвечает за результат задачи. Ревью проводит другой участник.
Подробные требования находятся в файлах `specs/` с соответствующим номером.

| Спецификация | Что сделать | Исполнитель / ревью | Критерии оценки |
|---|---|---|---|
| 001 — Исследование OpenCode | Установить OpenCode, записать версию. Сделать минимальный плагин. Проверить: получение команды до выполнения, блокировку, ожидание ответа пользователя, однократное разрешение. Проверить отмену и ошибку плагина. Сохранить пример кода и инструкцию запуска. | Александр / Алексей | Для каждой возможности указан результат: работает, не работает или не проверена. Работающие возможности подтверждены запуском; ограничения описаны. |
| 002 — Минимальное ядро | После исследования 001 согласовать формат данных между ядром и адаптером. Сделать функцию оценки команды: для выбранной команды удаления вернуть «нужно подтверждение» и объяснение; для остальных — «правило не сработало». Добавить тесты. | Алексей / Кирилл | Все согласованные примеры проходят тесты. Ядро не зависит от OpenCode. Отсутствие срабатывания не обозначается как гарантия безопасности. |
| 003 — Адаптер OpenCode | После 001 и 002 подключить ядро к плагину. Передать команду в ядро, показать объяснение, дождаться решения. При отказе заблокировать команду, при однократном разрешении продолжить её выполнение. Отмену и ошибки обработать согласно спецификации. | Кирилл; Александр помогает с интеграцией / Алексей | На тестовом файле подтверждены: ожидание без удаления, отказ без удаления, удаление после разрешения. Повторный вызов требует нового решения. |
| 004 — Проверка интеграции | После 003 повторить запуск по инструкции. Проверить ожидание, отказ, разрешение, повторный вызов, отмену и ошибку. Записать шаги, ожидаемый и фактический результат; найденные дефекты передать разработчикам. | Александр / Кирилл | Все сценарии имеют результат и свидетельство проверки. Непроверенные сценарии и ограничения перечислены отдельно. |

Опасные действия проверяются только на специально созданных тестовых файлах.
Постоянные разрешения и поддержка других агентов в эти задачи не входят.
